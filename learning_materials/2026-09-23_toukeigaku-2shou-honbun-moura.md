# 統計学2章 本文網羅ノート

## 章全体の見取り図
2章は「確率分布を道具として使えるようにする章」です。写真で確認できた範囲では、離散型分布、連続型分布、同時分布、周辺分布、条件付き分布、独立性、期待値・分散、積率母関数、変数変換、正規分布から派生する分布まで扱っています。

! 2章演習で証明が出る式は、本文の分布定義や変数変換公式に戻るとほぼ処理できます。特に「確率の総和は1」「二項係数の変形」「ヤコビアン」「ガンマ積分」が頻出の芯です。

## 2.1 離散型の確率分布
### 離散一様分布
値 `1,2,...,n` をすべて同じ確率で取る分布です。
```
P(X=x)=1/n,  x=1,2,...,n
E[X]=(n+1)/2
Var(X)=(n^2-1)/12
```
具体例: サイコロなら `n=6` で `E[X]=3.5`、分散は `35/12` です。どの目も同じ確率という「基準モデル」です。

注意: 一様分布は「値が同じくらい出る」という仮定です。現実のデータが偏っていれば、一様分布を置くのは不自然です。

### ベルヌーイ分布
成功を1、失敗を0で表す分布です。
```
P(X=x)=p^x(1-p)^(1-x),  x=0,1
E[X]=p
Var(X)=p(1-p)
G(s)=E[s^X]=(1-p)+ps
```
具体例: コインで表を成功とし、表の確率が0.6なら `X~Bernoulli(0.6)` で、平均は0.6です。

### 二項分布
独立なベルヌーイ試行をn回足した分布です。
```
X=X1+...+Xn,  Xi~Bernoulli(p)
P(X=x)=C(n,x)p^x(1-p)^(n-x)
E[X]=np
Var(X)=np(1-p)
G(s)=(1-p+ps)^n
```
具体例: 成功確率0.2の作業を10回行うとき、成功回数は `B(10,0.2)`。平均は2回、分散は1.6です。

演習での使い方: `E[X(X-1)]` を使うと分散の証明が短くなります。

### ポアソン分布
一定時間・一定領域内に起きる回数のモデルです。
```
P(X=x)=exp(-λ)λ^x/x!,  x=0,1,2,...
E[X]=λ
Var(X)=λ
G(s)=exp(λ(s-1))
```
具体例: 1時間あたり平均3件の問い合わせが来るなら、1時間の件数を `Poisson(3)` と近似できます。

二項分布との関係:
```
B(n,p) で nが大きく pが小さく np=λ が一定
→ Poisson(λ)
```
これは「まれな事象がたくさんの機会で起きる」状況です。

### 超幾何分布
有限母集団から非復元抽出するときの成功数の分布です。
```
P(X=x)= C(M,x) C(N-M,n-x) / C(N,n)
E[X]=nM/N
Var(X)= n(M/N)(1-M/N)((N-n)/(N-1))
```
具体例: 100個中20個が不良品で、10個を戻さず抽出するときの不良品数です。二項分布と違い、1回取るごとに成功確率が変わります。

### 幾何分布
初めて成功するまでの失敗回数、または成功までの試行回数を表します。本文では「成功までの失敗回数」型が見えています。
```
P(X=x)=p(1-p)^x,  x=0,1,2,...
E[X]=(1-p)/p
Var(X)=(1-p)/p^2
```
具体例: 成功確率0.25で、初成功前の失敗回数の平均は3回です。

### 負の二項分布
r回成功するまでの失敗回数の分布です。幾何分布をr個足したものとして見られます。
```
P(X=x)=C(r+x-1,x)p^r(1-p)^x
E[X]=r(1-p)/p
Var(X)=r(1-p)/p^2
```
具体例: 成功確率0.5で3回成功するまでの失敗回数の平均は3です。

## 2.2 連続型の確率分布
### 連続一様分布
区間 `[a,b]` のどこも同じ密度を持つ分布です。
```
f(x)=1/(b-a),  a≤x≤b
E[X]=(a+b)/2
Var(X)=(b-a)^2/12
```
具体例: 0分から10分の間でランダムに待ち時間が決まるなら、平均は5分です。

### 正規分布
平均μ、分散σ^2の釣鐘型の分布です。
```
f(x)=1/sqrt(2πσ^2) exp{-(x-μ)^2/(2σ^2)}
X~N(μ,σ^2)
```
標準化:
```
Z=(X-μ)/σ ~ N(0,1)
```
具体例: テスト点が平均60、標準偏差10なら、80点は `Z=2` です。標準正規表で上側確率を読めます。

### 対数正規分布
`log X` が正規分布に従うとき、Xは対数正規分布です。正の値だけを取り、右に長い裾を持ちます。

具体例: 所得や株価のように、倍率的に増減する量に使われます。

### 指数分布
次に事象が起こるまでの待ち時間のモデルです。
```
f(x)=λ exp(-λx),  x≥0
E[X]=1/λ
Var(X)=1/λ^2
```
具体例: 平均待ち時間が5分なら `λ=1/5` です。

### ガンマ分布
指数分布の和を一般化した分布です。率パラメータβの形では
```
f(x;α,β)=β^α/Γ(α) x^(α-1) exp(-βx),  x>0
E[X]=α/β
Var(X)=α/β^2
```
具体例: 1件の到着待ちが指数分布なら、3件目までの待ち時間はガンマ分布になります。

再生性:
```
X~Ga(α1,β), Y~Ga(α2,β), 独立
→ X+Y~Ga(α1+α2,β)
```
演習2.4のような比の問題では、和と比に変数変換し、ヤコビアンを掛けます。

### ベータ分布
0から1の範囲の割合を表す分布です。
```
f(x)= Γ(α+β)/(Γ(α)Γ(β)) x^(α-1)(1-x)^(β-1)
```
具体例: 成功確率pそのものを確率変数として扱うときに使われます。ガンマ分布の比とも関係します。

### カイ二乗分布・t分布・F分布
標準正規から作られる重要分布です。
```
Z1,...,Zν 独立 N(0,1)
→ Z1^2+...+Zν^2 ~ χ^2_ν

T=Z/sqrt(U/ν), Z~N(0,1), U~χ^2_ν
→ T~t_ν

F=(U1/ν1)/(U2/ν2)
→ F~F(ν1,ν2)
```
具体例: 母分散未知の平均の信頼区間はt分布、分散の信頼区間はカイ二乗分布、2つの分散比の検定はF分布を使います。

## 2.3 同時分布・周辺分布・条件付き分布
### 同時確率と周辺確率
2変数X,Yを同時に見るとき、離散型なら同時確率関数 `p(x,y)`、連続型なら同時密度 `f(x,y)` を使います。
```
離散: P(X=x,Y=y)=p(x,y)
連続: P((X,Y)∈A)=∫∫_A f(x,y) dxdy
```
周辺分布は、見ない変数を足す・積分して消します。
```
離散: p_X(x)=Σ_y p(x,y)
連続: f_X(x)=∫ f(x,y) dy
```
具体例: 学生の「数学点X」と「英語点Y」の同時分布から、数学点だけの分布を知りたいならYについて合計します。

### 条件付き分布
ある値がわかった後の分布です。
```
離散: P(X=x | Y=y)=p(x,y)/p_Y(y)
連続: f_{X|Y}(x|y)=f(x,y)/f_Y(y)
```
具体例: 全体の数学点分布ではなく、「英語が80点の人」に限った数学点分布を見るのが条件付き分布です。

### 独立性
同時分布が周辺分布の積に分解できると独立です。
```
離散: p(x,y)=p_X(x)p_Y(y)
連続: f(x,y)=f_X(x)f_Y(y)
```
注意: 無相関 `Cov(X,Y)=0` は独立より弱い条件です。正規分布の特別な場合を除き、無相関だから独立とは言えません。

### 共分散と相関係数
```
Cov(X,Y)=E[(X-E[X])(Y-E[Y])]
        =E[XY]-E[X]E[Y]

ρ=Cov(X,Y)/(sqrt(Var(X))sqrt(Var(Y)))
```
具体例: 勉強時間Xと点数Yの相関が正なら、勉強時間が長いほど点数も高い傾向です。ただし因果関係は別問題です。

## 2.4 変数変換
### 1変数の変換
`Y=g(X)` が単調変換なら、密度は
```
f_Y(y)=f_X(g^{-1}(y)) |d g^{-1}(y)/dy|
```
です。最後の絶対値は、変数の目盛りが伸び縮みする分を補正します。

具体例: `Y=2X` なら `X=Y/2`、`dx/dy=1/2` なので密度は半分に薄まります。

### 2変数以上の変換
多変数ではヤコビアンを使います。
```
f_{U,V}(u,v)=f_{X,Y}(x(u,v),y(u,v)) |J|
```
ここで
```
J = det ∂(x,y)/∂(u,v)
```
です。

演習2.4では、`x1,x2,x3` を `u,v,s` に変換して、ヤコビアン `s^2(1-u)` が出ます。これを忘れると密度が正規化されません。

## 2.5 積率母関数・確率母関数
### 積率母関数
```
M(t)=E[exp(tX)]
```
微分して `t=0` を代入するとモーメントが得られます。
```
M'(0)=E[X]
M''(0)=E[X^2]
```
また、独立な和では積になります。
```
X,Y 独立 → M_{X+Y}(t)=M_X(t)M_Y(t)
```
具体例: 独立な正規分布の和が正規分布になることは、積率母関数で確認できます。

### 確率母関数
非負整数値の確率変数では
```
G(s)=E[s^X]
```
を使います。二項分布やポアソン分布の和を扱うときに便利です。

## 2.6 章の横断的な注意
- 「確率関数」と「確率密度」は違います。連続型では一点の確率は0で、区間の面積が確率です。
- 分布のパラメータ表記は本によって違います。ガンマ分布は尺度パラメータか率パラメータかを必ず確認します。
- 和の分布を出すときは、独立性が前提になっていることが多いです。
- 変数変換では、逆変換の範囲とヤコビアンを必ず書きます。

## ミニ確認問題
1. `X~B(10,0.3)` の平均と分散を求めよう。
2. `X~Poisson(4)` なら `P(X=2)` はどう書けるか。
3. `X~N(50,10^2)` で `X=70` の標準化値を求めよう。
4. 同時密度から周辺密度を求めるとき、なぜ片方の変数で積分するのか説明しよう。

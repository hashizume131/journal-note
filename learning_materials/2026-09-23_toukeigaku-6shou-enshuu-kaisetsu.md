# 統計学6章演習 解説ノート

## 今日のテーマ
6章は、データ解析の結果を読んで説明する章です。主役は「重回帰分析」「主成分分析」「単回帰の手計算」「ポアソン分布の適合度検定」です。

## 問6.1 重回帰分析の結果を読む
### (1) 重回帰モデルの通常の仮定
モデルは
```
Y_i = β + β1 x_1i + β2 x_2i + ε_i
```
です。通常は次の仮定を置きます。
- 誤差の平均は0: `E[ε_i]=0`
- 誤差の分散は一定: `Var(ε_i)=σ^2`
- 誤差どうしは独立: `Cov(ε_i, ε_j)=0`
- 検定を正確に行うため、誤差は正規分布に従うと仮定することが多い
- 説明変数の間に完全な線形関係がない

最後の条件は特に大切です。説明変数が完全に重なると、それぞれの係数を一意に決められません。

### (2) Listening と Reading による重回帰
推定された回帰式は、おおよそ
```
Score = -1.938 + 0.099 Listening + 0.194 Reading
```
です。

重相関係数は `0.793`、決定係数は `0.629`、自由度調整済み決定係数は `0.523` です。これは、Listening と Reading を一緒に使うと、Score のばらつきの約63%を説明できる、という意味です。

分散分析表では `F = 5.926`、`P = 0.031` です。5%有意水準なら、モデル全体としては「Score と説明変数の間に関係がある」と判断できます。

一方、係数ごとの検定では
- Listening: 係数 `0.099`、P値 `0.457`
- Reading: 係数 `0.194`、P値 `0.141`

となり、どちらも単独では5%水準で有意とはいえません。これは「モデル全体は効いているが、2変数を同時に入れると個別の効果ははっきりしない」という状況です。Listening と Reading が互いに相関しているため、効果を分けにくくなっていると考えられます。

### (3) 1変数だけを使った単回帰との比較
単回帰の結果は次のように読めます。
```
Listeningのみ: 係数 0.254, P値 0.026, 決定係数 0.483, 調整済み 0.418
Readingのみ:   係数 0.262, P値 0.009, 決定係数 0.596, 調整済み 0.545
Totalのみ:     係数 0.148, P値 0.007, 決定係数 0.619, 調整済み 0.572
```
単独で見ると、Reading や Total は Score とかなり強く関係しているように見えます。Total は Listening と Reading の合計なので、2つの情報をまとめて持っており、単回帰では最も説明力が高くなっています。

ただし、Total は Listening と Reading の合計です。そのため、Total を入れると「Listening と Reading を別々に入れた重回帰」とは違い、2つを合わせた総合力を見ていることになります。

### (4) Listening, Reading, Total を同時に入れられるか
同時には入れられません。理由は
```
Total = Listening + Reading
```
という完全な線形関係があるからです。これは完全な多重共線性です。この場合、回帰係数の組み合わせが一意に決まらないため、通常の重回帰分析は実行できません。

## 問6.2 主成分分析と因子分析
### (1) 記述統計・相関・主成分分析・因子分析をやさしく説明
記述統計は、平均・標準偏差・相関係数などでデータの特徴を短く要約する方法です。

主成分分析は、複数の科目の点数を、少数の新しい軸にまとめる方法です。今回なら、第1主成分はどの科目にも正の重みがあるため「総合学力」と読むのが自然です。

因子分析は、観測された点数の背後にある見えない要因を考える方法です。たとえば「文系力」「理系力」のような潜在的な力が点数に表れている、と考えます。

### (2) 主成分分析と因子分析の違い
主成分分析は、データのばらつきをできるだけ失わずに圧縮する方法です。目的は「要約」です。

因子分析は、観測変数の背後にある共通因子を推定する方法です。目的は「背後の構造の説明」です。

同じような表や負荷量が出てきますが、主成分分析は合成得点を作る方法、因子分析は潜在因子を仮定する方法、と分けて考えると整理しやすいです。

### (3) 主成分分析の結果の読み方
固有値は
```
第1主成分 3.030, 第2主成分 1.219, 第3主成分 0.431, 第4主成分 0.178, 第5主成分 0.143
```
です。寄与率は
```
第1主成分 60.6%
第2主成分 24.4%
累積で第2主成分まで 85.0%
```
なので、第1・第2主成分まで見れば、全体の情報のかなり大きな部分を説明できます。

第1主成分の固有ベクトルは全科目で正です。したがって「全科目に共通する総合力」と解釈できます。

第2主成分は、国語・社会が正、数学・理科が負です。したがって「文系科目と理系科目の対比」と読むのが自然です。

### (4) 因子負荷量の見方
第1因子の負荷量は、国語・社会・数学・理科・英語のすべてで大きく正です。これは第1因子が「全体的な学力」を表すことを示します。

第2因子は、国語・社会が正、数学・理科が負です。英語は小さめです。したがって「文系寄りか理系寄りか」を表す軸として読めます。

バイプロットを描くなら、横軸を第1因子、縦軸を第2因子にして、国語・社会は右上、数学・理科は右下、英語は右寄りで縦方向は中間あたりに置きます。

## 問6.3 単回帰の手計算
### 与えられた値
`x = 0, 1, 2, 3, 4` で、平均は `x̄ = 2.0`、偏差平方和は
```
A_x = Σ(x_i - x̄)^2 = 10.0
```
です。3つの目的変数について、平均・偏差平方和・偏差積和は次の通りです。
```
y(1): 平均 1.1, A_y = 3.7,  A_xy = 5.0
y(2): 平均 2.1, A_y = 11.2, A_xy = 10.0
y(3): 平均 4.1, A_y = 41.2, A_xy = 20.0
```

### (1) 回帰直線
単回帰では
```
b = A_xy / A_x
a = ȳ - b x̄
```
です。したがって
```
y(1): b=0.5, a=0.1  したがって yhat = 0.1 + 0.5x
y(2): b=1.0, a=0.1  したがって yhat = 0.1 + 1.0x
y(3): b=2.0, a=0.1  したがって yhat = 0.1 + 2.0x
```
3本とも切片は同じで、傾きだけが大きくなっています。

### (2) 散布図の読み方
3つのデータはどれも右上がりです。`y(3)` は傾きが大きいので、xが増えるとyが大きく増えます。ただし、回帰直線からのずれの大きさは3つとも同程度になるように作られています。

### (3) 決定係数・寄与率・残差平方和
決定係数は
```
R^2 = A_xy^2 / (A_x A_y)
```
です。
```
y(1): R^2 = 25/37  ≈ 0.676
y(2): R^2 = 100/112 ≈ 0.893
y(3): R^2 = 400/412 ≈ 0.971
```
xとの直線関係は `y(3)` が最も強く、次に `y(2)`、最後に `y(1)` です。

回帰によって説明される平方和は `SSR = R^2 A_y`、残差平方和は `SSE = A_y - SSR` です。3つとも
```
SSE = 1.2
```
になります。残差分散の不偏推定値は、自由度 `5-2=3` で割るので
```
s^2 = 1.2/3 = 0.4
```
です。

### (4) 予測の不確かさ
回帰直線のまわりのばらつきは、3つとも `s^2=0.4` です。つまり、傾きや相関の強さは違っても、直線からの縦方向のずれの大きさは同じです。

### (5) y(2) の条件付き期待値の95%信頼区間
`y(2)` の回帰直線は
```
m0 = 0.1 + x0
```
です。xが `x0` のときの平均的なyの95%信頼区間は
```
m0 ± t_0.025(3) s sqrt(1/n + (x0 - x̄)^2 / A_x)
```
ここで `n=5`, `x̄=2`, `A_x=10`, `s=sqrt(0.4)`、`t_0.025(3)≈3.182` です。

個人1人の予測区間を出すときは、平方根の中にさらに `1` を足します。平均の信頼区間より予測区間の方が広くなります。

## 問6.4 ポアソン分布の最尤推定と適合度検定
### 問題の整理
96試合のゴール数データです。ゴール数の合計は
```
t = 101
```
なので、標本平均は
```
x̄ = 101/96 ≈ 1.052
```
です。

### (1) ポアソン分布と考えられる理由
ゴール数は非負の整数です。一定時間内に起こる回数を数えているので、まずはポアソン分布を候補にできます。ただし、実際のサッカーではチーム力・対戦相手・ホーム/アウェイなどで得点率が変わるため、完全に同じポアソン分布とみなせるかは検定で確認します。

### (2) λ の最尤推定量
ポアソン分布では、最尤推定量は標本平均です。
```
λhat = x̄ = 101/96 ≈ 1.052
```
このデータでは、1試合あたり平均約1.05ゴールと推定されます。

### (3) 適合度検定
期待度数が5以下になる階級はまとめます。階級をまとめた上で、カイ二乗統計量は
```
χ^2 ≈ 0.774
```
となり、P値は
```
P ≈ 0.856
```
です。P値が大きいので、「このデータはポアソン分布に従う」という帰無仮説を棄却しません。

大事なのは「ポアソン分布であると証明された」ではなく、「このデータからはポアソン分布と矛盾するとまではいえない」という読み方です。

### (4) λ の95%信頼区間
ワルド型の近似では
```
λhat ± 1.96 sqrt(λhat/n)
= 1.052 ± 0.205
= (0.847, 1.257)
```
です。

スコア型の近似を使うと
```
1.073 ± 0.210 = (0.863, 1.283)
```
となります。どちらも、λはおおよそ0.85から1.28の範囲にありそうだ、という解釈です。

## よくあるつまずき
- 重回帰で「モデル全体は有意」でも「各係数が有意」とは限りません。説明変数どうしの相関があると、個別の効果を分けにくくなります。
- 主成分分析の第1主成分は、固有ベクトルの符号を見て解釈します。すべて正なら総合力と読みやすいです。
- 適合度検定では期待度数が小さい階級をまとめます。小さい階級をそのまま使うとカイ二乗近似が不安定になります。

## 確認問題
1. Total を Listening と Reading と同時に重回帰へ入れると、なぜ係数が一意に決まらないのでしょうか。
2. 主成分分析で「第1主成分の寄与率60.6%」とは、何の60.6%を説明しているという意味でしょうか。
3. ポアソン適合度検定でP値が0.856だったとき、「ポアソン分布である」と断言してよいでしょうか。

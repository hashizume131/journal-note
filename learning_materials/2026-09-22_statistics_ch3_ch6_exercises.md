# 第3章: 推定量と最尤推定

## 問3.1 変換 Y = log(1+X) と推定量 T

### 問題の整理

確率密度関数が

```text
f(x; theta) = theta (1+x)^(-(1+theta)),  theta > 0, x > 0
```

である母集団から、独立同分布標本 X1, ..., Xn を取る。  
Y = log(1+X) と変換し、T = (1/n) sum log(1+Xi) を考える。

### (1) Y の密度、平均、分散

変換は

```text
y = log(1+x)
x = e^y - 1
dx/dy = e^y
```

なので、変数変換の公式より

```text
g(y) = f(e^y - 1; theta) * e^y
     = theta (e^y)^(-(1+theta)) * e^y
     = theta e^(-theta y),  y > 0
```

つまり Y はパラメータ theta の指数分布に従う。

指数分布 Exp(theta) の平均と分散は

```text
E[Y] = 1/theta
Var(Y) = 1/theta^2
```

である。

### (2) T が 1/theta の一致推定量であること

T は Y_i = log(1+X_i) の標本平均である。

```text
T = (Y1 + ... + Yn) / n
```

Y_i は平均 1/theta、分散 1/theta^2 の独立同分布なので、大数の法則より

```text
T -> E[Y] = 1/theta
```

となる。したがって T は 1/theta の一致推定量である。

### (3) T が不偏推定量で、分散がクラメール＝ラオ下限に一致すること

不偏性は期待値を取ればよい。

```text
E[T] = E[(Y1 + ... + Yn)/n]
     = (1/n)(E[Y1] + ... + E[Yn])
     = 1/theta
```

よって T は 1/theta の不偏推定量である。

分散は独立性より

```text
Var(T) = Var((Y1 + ... + Yn)/n)
       = (1/n^2) * n * Var(Y)
       = 1/(n theta^2)
```

次に、1/theta を推定する不偏推定量のクラメール＝ラオ下限を確認する。  
1標本の対数尤度は

```text
log f(x; theta) = log theta - (1+theta) log(1+x)
```

微分すると

```text
d/dtheta log f(x; theta) = 1/theta - log(1+x)
d^2/dtheta^2 log f(x; theta) = -1/theta^2
```

1標本のフィッシャー情報量は

```text
I(theta) = -E[d^2/dtheta^2 log f(X; theta)] = 1/theta^2
```

n標本では

```text
I_n(theta) = n/theta^2
```

推定したい量を tau(theta) = 1/theta とおくと

```text
tau'(theta) = -1/theta^2
```

クラメール＝ラオ下限は

```text
{tau'(theta)}^2 / I_n(theta)
= (1/theta^4) / (n/theta^2)
= 1/(n theta^2)
```

これは Var(T) と一致する。  
つまり T はこの意味で効率的な不偏推定量である。

### よくある間違い

- X の分布のまま平均を直接出そうとして計算が重くなる。
- Y = log(1+X) と置いた後のヤコビアン dx/dy = e^y を忘れる。
- 一致性と不偏性を同じものとして扱う。

## 問3.2 指数分布の最尤推定とデルタ法

### 問題の整理

X1, ..., Xn は指数分布

```text
f(x) = lambda e^(-lambda x),  x >= 0
```

に従う。T = X1 + ... + Xn、標本平均を Xbar = T/n とする。

### (1) 標本平均の期待値と分散

指数分布の平均と分散は

```text
E[X] = 1/lambda
Var(X) = 1/lambda^2
```

したがって

```text
E[Xbar] = 1/lambda
Var(Xbar) = 1/(n lambda^2)
```

### (2) lambda の最尤推定量

尤度は

```text
L(lambda) = product lambda e^(-lambda xi)
          = lambda^n e^(-lambda t)
```

対数尤度は

```text
ell(lambda) = n log lambda - lambda t
```

微分して0とおく。

```text
d ell/d lambda = n/lambda - t = 0
```

よって

```text
lambda_hat = n/t = 1/Xbar
```

### (3) n標本のフィッシャー情報量

1標本の対数尤度は

```text
log f(x; lambda) = log lambda - lambda x
```

2階微分は

```text
d^2/dlambda^2 log f(x; lambda) = -1/lambda^2
```

したがって

```text
i_n(lambda) = n/lambda^2
```

### (4) デルタ法で lambda_hat の漸近分散を求める

標本平均について

```text
Xbar approximately N(1/lambda, 1/(n lambda^2))
```

lambda_hat = 1/Xbar は、関数 g(x) = 1/x を Xbar に適用したもの。  
デルタ法より

```text
Var(g(Xbar)) approximately {g'(1/lambda)}^2 Var(Xbar)
```

ここで

```text
g'(x) = -1/x^2
g'(1/lambda) = -lambda^2
```

よって

```text
Var(lambda_hat) approximately lambda^4 * 1/(n lambda^2)
                         = lambda^2/n
```

最尤推定量の標準誤差は、おおよそ lambda / sqrt(n) と見ればよい。

# 第6章: 多変量解析と検定

## 問6.1 重回帰分析

### 問題の整理

入学時の英語テスト Listening と Reading を説明変数、期末試験の点数 Y を目的変数として、重回帰モデル

```text
Yi = beta0 + beta1 x1i + beta2 x2i + epsilon_i
```

を考える。

### (1) 重回帰モデルの通常の仮定

代表的な仮定は次の通り。

- E[epsilon_i] = 0: 誤差の平均は0
- Var(epsilon_i) = sigma^2: 誤差分散は一定
- Cov(epsilon_i, epsilon_j) = 0: 異なる観測の誤差は無相関
- 説明変数と誤差は独立、または少なくとも無相関
- 推測を行うときは誤差の正規性を仮定することが多い
- 強い多重共線性がないことが望ましい

### (2) 重回帰出力の読み方

画像から読める主な出力は次の通り。

```text
重相関係数 R = 0.793
決定係数 R^2 = 0.629
自由度調整済み R^2 = 0.523
F = 5.926, P = 0.031
```

意味は次のように読む。

- R = 0.793: 実測値 Y とモデルの予測値の相関がかなり高い。
- R^2 = 0.629: Y のばらつきの約62.9%を、Listening と Reading で説明している。
- 自由度調整済み R^2 = 0.523: 説明変数の個数を考慮すると説明力は約52.3%程度。
- F検定の P = 0.031: 「すべての回帰係数が0」という帰無仮説は5%水準で棄却される。

係数はおおよそ

```text
Yhat = -1.938 + 0.099 Listening + 0.194 Reading
```

ただし Listening の P値は 0.457、Reading の P値は 0.141 であり、個別には5%水準で有意とはいえない。

### 重要な解釈

全体としてはモデルに説明力があるが、Listening と Reading は互いに相関が高いため、重回帰に同時投入すると個々の係数の有意性が弱く見える。  
これが多重共線性の典型的な見え方である。

### (3) Listening のみ、Reading のみ、Total のみを説明変数にした場合

画像から読める単回帰の結果は次の通り。

| 説明変数 | 係数 | P値 | 決定係数 |
|---|---:|---:|---:|
| Listening のみ | 0.254 | 0.026 | 0.418 |
| Reading のみ | 0.262 | 0.009 | 0.545 |
| Total のみ | 0.148 | 0.007 | 0.572 |

3つとも単回帰では有意で、特に Total がもっとも決定係数が高い。

### (4) Listening・Reading・Total を同時に使うべきか

Total は Listening + Reading で作られているため、3つを同時に入れると説明変数どうしが完全に線形従属になる。  
そのため、通常の重回帰では同時投入すべきではない。

今回のデータでは、実用上は Total の単回帰が簡単で説明力も高い。  
Listening と Reading を分けて考察したい目的がある場合のみ、2変数の重回帰を使うとよい。

## 問6.2 主成分分析

### 問題の整理

5教科の得点、平均、標準偏差、相関行列、主成分分析の結果が与えられている。  
変数は国語、社会、数学、理科、英語である。

### (1) 記述統計量と相関行列の読み方

平均と標準偏差から、科目ごとの点数水準とばらつきが見える。

| 科目 | 平均 | 標準偏差 |
|---|---:|---:|
| 国語 | 58.400 | 13.810 |
| 社会 | 48.917 | 9.772 |
| 数学 | 44.033 | 13.769 |
| 理科 | 49.283 | 7.514 |
| 英語 | 50.508 | 7.503 |

相関行列からは次が読み取れる。

- 国語と社会: 0.840 と非常に高い。
- 数学と理科: 0.819 と非常に高い。
- 英語は国語・社会ともある程度相関がある。
- 国語と数学の相関は 0.206 と低め。

つまり「文系寄りの科目群」と「理系寄りの科目群」が見えやすいデータである。

### (2) 主成分分析とは

主成分分析は、複数の変数を少数の合成変数にまとめる方法である。  
相関行列を使う場合、各主成分は標準化された変数の線形結合として作られる。

```text
第1主成分 = a1 国語 + a2 社会 + a3 数学 + a4 理科 + a5 英語
```

固有値は、その主成分が持つ分散の大きさを表す。  
寄与率は「全体の情報のうち、その主成分が何割を説明するか」である。

### (3) 固有値・寄与率の解釈

画像から読める結果は次の通り。

| 主成分 | 固有値 | 寄与率 | 累積寄与率 |
|---|---:|---:|---:|
| 第1 | 3.030 | 0.606 | 0.606 |
| 第2 | 1.219 | 0.244 | 0.850 |
| 第3 | 0.431 | 0.086 | 0.936 |
| 第4 | 0.178 | 0.036 | 0.971 |
| 第5 | 0.143 | 0.029 | 1.000 |

第1主成分だけで約60.6%、第2主成分までで約85.0%を説明する。  
したがって、2次元に要約してもかなり多くの情報を保てる。

### (4) 固有ベクトルと主成分負荷量の解釈

第1主成分の係数は全科目で正で、だいたい同じ大きさである。

```text
第1主成分: 0.436 国語 + 0.487 社会 + 0.411 数学 + 0.435 理科 + 0.464 英語
```

これは「総合学力」を表す軸と解釈できる。  
全体的に点数が高い生徒ほど、第1主成分得点が高くなる。

第2主成分は、国語・社会が正、数学・理科が負になっている。

```text
第2主成分: 0.515 国語 + 0.364 社会 - 0.571 数学 - 0.512 理科 + 0.120 英語
```

これは「文系寄りか理系寄りか」を表す軸と解釈できる。  
第2主成分が高いほど文系科目寄り、低いほど理系科目寄りと読める。

### よくある間違い

- 固有値を「点数」と勘違いする。固有値は主成分の分散である。
- 寄与率だけ見て、主成分の意味を解釈しない。
- 主成分の符号に絶対的な意味を持たせる。主成分は全体の符号を反転しても同じ軸を表す。

## 問6.3 3組の回帰直線

### 問題の整理

同じ x = 0, 1, 2, 3, 4 に対して、3種類の y が与えられている。  
与えられた要約量は以下。

```text
xbar = 2.0, Ax = 10.0
ybar(1)=1.1, Ay(1)=3.7, Axy(1)=5.0
ybar(2)=2.1, Ay(2)=11.2, Axy(2)=10.0
ybar(3)=4.1, Ay(3)=41.2, Axy(3)=20.0
```

ここで

```text
Ax = sum (xi - xbar)^2
Ay = sum (yi - ybar)^2
Axy = sum (xi - xbar)(yi - ybar)
```

である。

### (1) 回帰直線を求める

単回帰直線は

```text
yhat = a + b x
b = Axy / Ax
a = ybar - b xbar
```

よって

| データ | b | a | 回帰直線 |
|---|---:|---:|---|
| y(1) | 0.5 | 0.1 | yhat = 0.1 + 0.5x |
| y(2) | 1.0 | 0.1 | yhat = 0.1 + 1.0x |
| y(3) | 2.0 | 0.1 | yhat = 0.1 + 2.0x |

### (2) 散布図の読み方

3組とも直線の傾きは異なるが、切片はいずれも 0.1 である。  
図を描くと、y(1) はゆるやか、y(2) は中くらい、y(3) は急な右上がりになる。

### (3) 決定係数を求める

単回帰の決定係数は

```text
R^2 = Axy^2 / (Ax Ay)
```

したがって

```text
R^2(1) = 5^2 / (10 * 3.7) = 25/37 = 0.676
R^2(2) = 10^2 / (10 * 11.2) = 100/112 = 0.893
R^2(3) = 20^2 / (10 * 41.2) = 400/412 = 0.971
```

y(3) がもっとも直線によく乗っている。

### (4) 残差分散の推定値

残差平方和は

```text
SSE = Ay - b Axy
```

である。

```text
SSE(1) = 3.7 - 0.5 * 5 = 1.2
SSE(2) = 11.2 - 1.0 * 10 = 1.2
SSE(3) = 41.2 - 2.0 * 20 = 1.2
```

単回帰では切片と傾きの2つを推定するので、自由度は n-2 = 3。  
したがって残差分散の推定値は

```text
s^2 = 1.2 / 3 = 0.4
```

3組すべてで同じになる。

### (5) y(2) の回帰直線の信頼区間

y(2) では

```text
yhat = 0.1 + 1.0x
s^2 = 0.4
n = 5
xbar = 2
Ax = 10
```

平均応答 m0 = a + b x0 の95%信頼区間は、おおよそ

```text
m0 ± t_(0.975, 3) * s * sqrt(1/n + (x0 - xbar)^2 / Ax)
```

である。  
ここで t_(0.975, 3) は自由度3の t分布の上側2.5%点で、約3.182である。

注意点: これは「平均的な直線の位置」の信頼区間であり、個々の新しい観測値の予測区間より狭い。

## 問6.4 ポアソン分布の適合度検定

### 問題の整理

ワールドカップの試合ごとのゴール数について、度数表が与えられている。  
読める度数は次の通り。

| ゴール数 | 0 | 1 | 2 | 3 | 4 | 5 | 6 | 7 | 合計 |
|---|---:|---:|---:|---:|---:|---:|---:|---:|---:|
| 度数 | 35 | 35 | 18 | 5 | 2 | 0 | 0 | 1 | 96 |

### (1) なぜポアソン分布を仮定するのか

ゴール数は「一定時間内に何回イベントが起きるか」を数えるデータである。  
各試合でゴールが独立に、平均的な発生率に従って起きると近似できるなら、ポアソン分布を候補にできる。

ただし現実にはチーム力、戦術、延長の有無などの影響があるため、完全な仮定ではなく近似モデルである。

### (2) lambda の推定

ポアソン分布の平均は lambda なので、標本平均で推定する。

```text
lambda_hat = 合計ゴール数 / 試合数
           = 101 / 96
           = 1.052
```

### (3) 期待度数とセルの結合

lambda_hat = 1.052 として期待度数を計算すると、おおよそ次のようになる。

| ゴール数 | 観測度数 | 期待度数 |
|---|---:|---:|
| 0 | 35 | 33.524 |
| 1 | 35 | 35.270 |
| 2 | 18 | 18.554 |
| 3 | 5 | 6.507 |
| 4以上 | 3 | 2.146 |

画像の解答では、4以上をまとめた形でカイ二乗統計量が計算されていると読める。

### (4) 適合度検定

検定統計量は

```text
X^2 = sum (観測度数 - 期待度数)^2 / 期待度数
```

上の区分では

```text
X^2 = 0.773 付近
```

となる。  
パラメータ lambda をデータから1つ推定しているので、自由度は

```text
自由度 = セル数 - 1 - 推定パラメータ数
       = 5 - 1 - 1
       = 3
```

画像の解答では P値は約 0.856 と読める。  
P値が十分大きいため、ポアソン分布に従うという仮定を棄却する根拠はない。

### よくある間違い

- lambda を既知として扱い、自由度を1つ多くしてしまう。
- 期待度数が小さいセルをそのまま細かく分けすぎる。
- 「棄却できない」を「ポアソン分布であると証明できた」と言い換えてしまう。

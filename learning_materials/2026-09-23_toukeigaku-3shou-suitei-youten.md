# 統計学3章 推定の要点PDF

## 今日のテーマ
3章は、母集団の未知パラメータを標本から推定する章です。写真では、標本平均・標本分散、不偏性、一致性、最尤推定、フィッシャー情報量、クラメール・ラオ下限、信頼区間が中心でした。

## 1. 推定量を見るときの3つの観点
推定量は、未知パラメータを標本から計算するルールです。たとえば母平均μを推定するなら標本平均
```
X̄ = (1/n)ΣX_i
```
を使います。

大事な性質は次の3つです。
- 不偏性: `E[T]=θ`。平均的に真の値を当てる。
- 一致性: `n→∞` で `T` が `θ` に近づく。
- 効率性: 同じ不偏推定量の中で分散が小さい。

不偏性は「平均的にズレない」、一致性は「データが増えたら当たる」です。似ていますが別の性質です。

## 2. 標本平均と標本分散
独立同分布で `E[X_i]=μ`, `Var(X_i)=σ^2` のとき
```
E[X̄] = μ
Var(X̄) = σ^2/n
```
です。標本数nが増えるほど、標本平均のばらつきは小さくなります。

標本分散には2種類あります。
```
S_n^2 = (1/n)Σ(X_i-X̄)^2
S^2 = (1/(n-1))Σ(X_i-X̄)^2
```
不偏推定量になるのは後者です。理由は、標本平均をデータから推定しているぶん自由度が1つ減るからです。

## 3. 最尤推定
最尤推定は、観測されたデータが最も起こりやすくなるパラメータを選ぶ方法です。

独立標本なら尤度は積です。
```
L(θ) = Π f(x_i;θ)
```
計算では対数を取って
```
ℓ(θ) = log L(θ)
```
を最大化します。積が和になり、微分しやすくなります。

### 例: 指数分布
`f(x;λ)=λ exp(-λx)` なら
```
ℓ(λ)=n log λ - λΣx_i
```
微分して0に置くと
```
λhat = n / Σx_i = 1/X̄
```
です。

## 4. フィッシャー情報量
フィッシャー情報量は、データがパラメータについてどれだけ情報を持つかを表します。
```
I(θ) = E[{∂ log f(X;θ)/∂θ}^2]
```
独立なn個の標本では、情報量は足し算されます。
```
I_n(θ) = n I(θ)
```
情報量が大きいほど、理論的に推定量の分散を小さくできます。

## 5. クラメール・ラオ下限
`τ(θ)` を推定する不偏推定量Tについて
```
Var(T) ≥ {τ'(θ)}^2 / I_n(θ)
```
が成り立ちます。特に `τ(θ)=θ` なら
```
Var(T) ≥ 1/I_n(θ)
```
です。

注意点は、推定対象がθそのものではない場合です。たとえば `1/θ` を推定するなら、`τ'(θ)` を入れます。

## 6. デルタ法
デルタ法は、推定量に関数をかけたときの近似分散を出す方法です。

もし
```
T ≈ N(θ, V)
```
なら
```
g(T) ≈ N(g(θ), {g'(θ)}^2 V)
```
と近似します。

たとえば `λhat=1/X̄` のように、標本平均を変換した推定量の分散を近似するときに使います。

## 7. 信頼区間
母平均の信頼区間は、母分散が既知か未知かで形が変わります。

母分散既知なら標準正規を使い、
```
X̄ ± z_(α/2) σ/√n
```
母分散未知ならt分布を使い、
```
X̄ ± t_(α/2,n-1) S/√n
```
です。

信頼区間は「この区間に真の値が確率95%で入っている」と読むより、「同じ方法で何度も区間を作ると、そのうち約95%が真の値を含む」と読むのが正確です。

## 確認問題
1. 不偏性と一致性の違いを一文で説明しよう。
2. なぜ標本分散ではnではなくn-1で割ると不偏になるのか、自由度という言葉を使って説明しよう。
3. 推定対象が `τ(θ)=1/θ` のとき、クラメール・ラオ下限に `τ'(θ)` が必要な理由を確認しよう。

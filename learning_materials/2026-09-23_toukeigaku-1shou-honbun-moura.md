# 統計学1章 本文網羅ノート

## 章全体の見取り図
1章は、統計学で使う確率の言葉を整える章です。写真で確認できた流れは、§1.1 事象と確率、§1.2 確率分布と母関数、§1.3 分布の特性値、§1.4 条件付き分布、§1.5 極限定理と確率分布の近似です。

! ここで大事なのは、公式を暗記することより「何を確率変数と見るか」「どの分布で表すか」「平均・分散・条件付きで何が変わるか」を言葉にできることです。

## §1.1 事象と確率
### 試行・標本点・標本空間・事象
試行とは、結果が偶然に左右される操作です。1回サイコロを振る、製品を1個検査する、患者に薬を投与して効果の有無を見る、などが試行です。標本点は起こりうる個々の結果、標本空間 Ω は標本点をすべて集めた集合、事象は標本空間の部分集合です。

```
サイコロ1回: Ω={1,2,3,4,5,6}
A={偶数が出る}={2,4,6}
B={4以上が出る}={4,5,6}
```

具体例: A∩B={4,6} は「偶数かつ4以上」、A∪B={2,4,5,6} は「偶数または4以上」です。A^c={1,3,5} は「偶数でない」です。

### 和事象・積事象・補事象・排反
和事象 A∪B は「AまたはB」、積事象 A∩B は「AかつB」、補事象 A^c は「Aが起こらない」です。A∩B=∅ のとき、AとBは排反です。

! 排反と独立は別物です。排反は同時に起こらないこと、独立は一方を知っても他方の確率が変わらないことです。サイコロで「偶数」と「奇数」は排反ですが、片方が起きたらもう片方は絶対に起きないので独立ではありません。

### 確率の基本法則
確率 P(A) は、事象Aがどれくらい起こりやすいかを0から1で表す数です。

```
0 ≦ P(A) ≦ 1
P(Ω)=1,  P(∅)=0
P(A^c)=1-P(A)
P(A∪B)=P(A)+P(B)-P(A∩B)
A∩B=∅ なら P(A∪B)=P(A)+P(B)
```

具体例: サイコロで A={偶数}, B={4以上} のとき、P(A)=3/6、P(B)=3/6、P(A∩B)=2/6 なので、P(A∪B)=3/6+3/6-2/6=4/6 です。

## 条件付き確率・乗法定理・独立性・ベイズの定理
### 条件付き確率
Bが起こったという情報を得た後でAが起こる確率を、条件付き確率 P(A|B) といいます。

```
P(A|B)=P(A∩B)/P(B)  （P(B)>0）
P(A∩B)=P(A|B)P(B)=P(B|A)P(A)
```

具体例: サイコロで B={4以上} と知った後、A={偶数} の確率は、Bの中の {4,5,6} のうち偶数が {4,6} なので P(A|B)=2/3 です。

### 独立性
AとBが独立とは、Bが起こったと知ってもAの確率が変わらないことです。

```
P(A|B)=P(A)
同値に P(A∩B)=P(A)P(B)
```

具体例: 2回サイコロを振るとき、A={1回目が偶数} と B={2回目が6} は独立です。1回目の結果を知っても2回目の6の確率は1/6のままです。

### ベイズの定理
原因や状態を後から推定するときに使う式です。

```
P(A|B)= P(B|A)P(A) / P(B)
P(B)=P(B|A)P(A)+P(B|A^c)P(A^c)
```

具体例: 病気の有病率が1%、病気の人が陽性になる確率が99%、病気でない人が陽性になる確率が5%なら、陽性後に本当に病気である確率は 0.99×0.01 / (0.99×0.01+0.05×0.99) ≒ 0.167 です。検査が高性能でも、まれな病気では事前確率が効きます。

## §1.2 確率分布と母関数
### 確率変数
確率変数 X は、偶然の結果を数値に対応させる関数です。サイコロの目なら X=1,...,6、製品検査なら X=1(不良) または0(良品) のように置けます。

! 確率変数は「変数」と呼ぶけれど、標本点から数値への対応です。何をXにするかで、同じ試行でも分布が変わります。

### 離散型確率変数
離散型は、とびとびの値をとる確率変数です。確率関数 f_X(x)=P(X=x) で表します。

```
f_X(x) ≧ 0
Σ_x f_X(x)=1
P(a≦X≦b)=Σ_{a≦x≦b} f_X(x)
```

具体例: ベルヌーイ分布は成功を1、失敗を0で表します。P(X=1)=p、P(X=0)=1-p です。二項分布は、独立なベルヌーイ試行をn回行った成功回数です。

### 連続型確率変数
連続型は、区間内の任意の値を取りうる確率変数です。確率密度関数 f_X(x) で表します。連続型では一点の確率 P(X=a) は通常0で、区間の面積が確率です。

```
f_X(x) ≧ 0
∫_{-∞}^{∞} f_X(x)dx = 1
P(a≦X≦b)=∫_a^b f_X(x)dx
F_X(x)=P(X≦x)=∫_{-∞}^x f_X(t)dt
```

具体例: 0から1まで一様に選ぶなら f_X(x)=1 (0≦x≦1) で、P(0.2≦X≦0.5)=0.3 です。

### 期待値
期待値 E[X] は、長く繰り返したときの平均的な値です。離散型は和、連続型は積分で計算します。

```
離散型: E[X]=Σ_x x f_X(x)
連続型: E[X]=∫_{-∞}^{∞} x f_X(x)dx
関数の期待値: E[g(X)]=Σ g(x)f_X(x) または ∫ g(x)f_X(x)dx
```

具体例: 公平なサイコロの期待値は (1+2+3+4+5+6)/6=3.5 です。実際の1回の目が3.5になるわけではなく、何度も振った平均が3.5に近づくという意味です。

### モーメントと母関数
原点まわりのk次モーメントは E[X^k]、平均まわりのk次モーメントは E[(X-E[X])^k] です。積率母関数 M_X(t)=E[e^{tX}] は、微分するとモーメントを取り出せる関数です。

```
M_X(t)=E[e^{tX}]
M_X'(0)=E[X]
M_X''(0)=E[X^2]
独立な X,Y なら M_{X+Y}(t)=M_X(t)M_Y(t)
```

使いどころ: 和の分布を調べるとき、母関数の積にできると計算が軽くなります。二項分布がベルヌーイ分布の和として扱えるのもこの考え方です。

## §1.3 分布の特性値
### 平均・分散・標準偏差
平均は分布の中心、分散は中心からの散らばり、標準偏差は分散の平方根で元の単位に戻した散らばりです。

```
μ=E[X]
V(X)=E[(X-μ)^2]=E[X^2]-{E[X]}^2
SD(X)=√V(X)
V(aX+b)=a^2 V(X)
```

具体例: ベルヌーイ分布 X∈{0,1}, P(X=1)=p では E[X]=p、E[X^2]=p なので V(X)=p-p^2=p(1-p) です。

### 共分散と相関係数
2つの確率変数 X,Y が一緒に増えやすいかを測るのが共分散、単位の影響を除いて -1 から1に標準化したものが相関係数です。

```
Cov(X,Y)=E[(X-E[X])(Y-E[Y])]
        =E[XY]-E[X]E[Y]
ρ=Cov(X,Y)/(√V(X)√V(Y))
-1≦ρ≦1
```

具体例: 身長Xと体重Yは一般に正の相関を持ちます。ただし相関があることは「XがYの原因である」ことを意味しません。

注意: 独立なら Cov(X,Y)=0 ですが、Cov(X,Y)=0 だから必ず独立とは限りません。線形の関係だけを見ているからです。

## §1.4 条件付き分布
### 条件付き分布の考え方
条件付き分布は、ある情報を得た後で確率分布を更新したものです。離散型では条件付き確率の表、連続型では条件付き密度で表します。

```
離散型: P(X=x | Y=y)=P(X=x, Y=y)/P(Y=y)
連続型: f_{X|Y}(x|y)=f_{X,Y}(x,y)/f_Y(y)
条件付き期待値: E[X|Y=y]
```

具体例: 袋に赤玉と白玉があり、1個目が赤だったという情報を得ると、2個目が赤である確率は元の確率と変わります。条件を入れた瞬間に「標本空間を狭めている」と考えると読みやすいです。

### 独立との関係
XとYが独立なら、Yを知ってもXの分布は変わりません。

```
f_{X,Y}(x,y)=f_X(x)f_Y(y)
P(X=x | Y=y)=P(X=x)
E[X|Y=y]=E[X]
```

具体例: 2回サイコロを振るとき、1回目の目Xと2回目の目Yは独立です。Y=6と知ってもXの分布は1から6の一様分布のままです。

## §1.5 極限定理と確率分布の近似
### チェビシェフの不等式
平均から大きく外れる確率を、分散だけで上から押さえる不等式です。分布の形が分からなくても使えます。

```
任意の ε>0 に対して
P(|Z-E[Z]| ≧ ε) ≦ V(Z)/ε^2
```

具体例: ある量Zの平均が50、分散が16なら、平均との差が10以上になる確率は高くても 16/100=0.16 です。実際の確率はもっと小さいかもしれませんが、最大でも16%と言えます。

### 大数の弱法則
独立に同じ分布から得た X_1,...,X_n の標本平均 X̄ は、nが大きくなるほど母平均 μ に近づきます。

```
X̄=(X_1+...+X_n)/n
E[X̄]=μ
V(X̄)=σ^2/n
P(|X̄-μ|≧ε) ≦ σ^2/(nε^2) → 0
```

意味: サイコロを何回も振ると、標本平均は3.5に近づきます。1回1回の結果はばらついても、平均のばらつきは n 分の1に小さくなります。

### 中心極限定理
独立同分布の和や平均は、元の分布が正規分布でなくても、nが大きいと正規分布で近似できます。

```
E[X_i]=μ, V(X_i)=σ^2 のとき
Z=(X̄-μ)/(σ/√n) は n が大きいと N(0,1) に近い
```

具体例: 不良率p=0.1の製品を400個調べると、不良個数Xは二項分布 Bin(400,0.1) です。平均は40、分散は36なので、Xはおよそ N(40,36) で近似できます。

### 確率分布の近似
分布近似は「厳密計算が重いときに、扱いやすい分布で置き換える」道具です。二項分布は n が大きく p が極端でないと正規分布で近似しやすく、まれな事象の回数はポアソン分布で近似することがあります。

! 近似では条件を確認します。nが小さい、pが0や1に近い、独立でない、同じ分布でない、といった場合は近似が悪くなります。

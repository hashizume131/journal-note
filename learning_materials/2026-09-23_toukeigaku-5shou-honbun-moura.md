# 統計学5章 本文網羅ノート

## 章全体の見取り図
5章は「主なデータ解析手法」です。写真で確認できた本文は、§5.1 分散分析、§5.2 回帰分析、§5.3 分割表の解析、§5.4 ノンパラメトリック法です。計量値データ、複数変数の関係、個数データ、順位データをどう扱うかをまとめる章です。

! 5章の中心は、データの変動を「説明できる部分」と「誤差・残差」に分け、比や検定統計量で判断することです。式だけ追うより、どの変動を比べているかを見るとつながります。

## §5.1 分散分析
### 5.1.1 一元配置分散分析
一元配置分散分析は、1つの要因Aが複数水準 A_1,...,A_a を持つとき、水準によって母平均が異なるかを調べる方法です。写真では各水準に r 個の観測値 x_{ij} がある形で説明されています。

```
x_{ij}=μ+α_i+ε_{ij}
Σ_i α_i=0
ε_{ij} は独立に N(0,σ^2) に従う
帰無仮説 H0: α_1=α_2=...=α_a=0
```

記号の意味: μ は全体の平均、α_i は水準 A_i の効果、ε_{ij} は偶然誤差です。H0は「水準の違いによる平均差はない」という仮説です。

### 平方和の分解
観測値全体のばらつきは、水準間のばらつきと水準内のばらつきに分けられます。

```
総平方和: S_T=Σ_iΣ_j (x_{ij}-x̄)^2
要因平方和: S_A=Σ_i r(x̄_i.-x̄)^2
誤差平方和: S_e=Σ_iΣ_j (x_{ij}-x̄_i.)^2
S_T=S_A+S_e
```

具体例: 3種類の肥料A1,A2,A3で作物の収量を比べるとします。各肥料内のばらつきが小さいのに、肥料ごとの平均が大きく離れていれば、肥料の種類が効いていそうです。

### F検定
分散分析では、要因による平均平方と誤差による平均平方の比を見ます。

```
V_A=S_A/(a-1)
V_e=S_e/{a(r-1)}
F=V_A/V_e
H0 の下で F は F(a-1, a(r-1)) に従う
```

なぜ比を取るか: 水準差がないなら、要因平方和も誤差平方和も同じ σ^2 を反映するはずです。要因側だけが大きすぎるなら、水準差があると判断します。

### 5.1.2 二元配置分散分析
二元配置分散分析は、2つの要因A,Bが同時にある場合です。例として、肥料の種類Aと水やり条件Bが収量に与える影響を見るような場面です。

```
x_{ijk}=μ+α_i+β_j+(αβ)_{ij}+ε_{ijk}
主効果A: Aの水準差
主効果B: Bの水準差
交互作用AB: Aの効果がBの水準で変わること
```

具体例: 肥料A1は少ない水で効くが、肥料A2は多い水で効くなら、肥料と水やりの交互作用があります。主効果だけを見ると見落とすことがあります。

! 分散分析の注意: 独立性、正規性、等分散性が前提です。平均に差があるかを調べる方法であり、どの組み合わせが違うかは多重比較など別の手順が必要です。

## §5.2 回帰分析
### 5.2.1 線形単回帰
線形単回帰は、説明変数Xで目的変数Yを直線的に説明する方法です。本文では Y=α+βX を回帰直線とし、観測データ (x_i,y_i) に対して残差平方和を最小にする α,β を求めています。

```
y_i=α+βx_i+ε_i
ε_i は独立に N(0,σ^2) に従う
残差 e_i=y_i-(α+βx_i)
S_e=Σ_i {y_i-α-βx_i}^2
```

最小二乗推定量は次の形です。

```
S_xx=Σ_i (x_i-x̄)^2
S_xy=Σ_i (x_i-x̄)(y_i-ȳ)
b=S_xy/S_xx
a=ȳ-bx̄
回帰直線: 予測値y=a+bx
```

意味: b は「Xが1増えるとYが平均的にどれだけ変わるか」です。a はX=0のときの予測値ですが、X=0が観測範囲外なら実質的な意味は薄いことがあります。

具体例: 勉強時間Xと点数Yで b=4 なら、勉強時間が1時間増えると点数は平均して4点高い、という線形関係を表します。ただし因果とは限りません。

### 回帰平方和・残差平方和・決定係数
Yの総変動は、回帰で説明された変動と残差変動に分かれます。

```
S_yy=Σ_i (y_i-ȳ)^2
S_R=Σ_i (予測値y_i-ȳ)^2
S_e=Σ_i (y_i-予測値y_i)^2
S_yy=S_R+S_e
R^2=S_R/S_yy=1-S_e/S_yy
```

R^2は決定係数で、Yの変動のうち回帰式で説明できた割合です。0.8なら「Yのばらつきの約80%をこの直線で説明した」と読めます。

### 回帰係数の検定
回帰直線が意味を持つかは、β=0 かどうかで見ます。β=0ならXが変わってもYの平均は変わらないので、線形関係がないという帰無仮説になります。

```
H0: β=0
t=b / se(b)
または F=V_R/V_e
単回帰では t^2 と F が対応する
```

注意: p値が小さくても、外れ値や非線形関係で見かけの傾きが出ることがあります。散布図と残差を見るのが大事です。

### 5.2.2 線形重回帰
重回帰は、複数の説明変数 X_1,...,X_p でYを説明します。

```
y_i=β_0+β_1x_{i1}+...+β_px_{ip}+ε_i
```

β_j は「他の説明変数を固定したとき、X_jが1増えるとYがどれだけ変わるか」です。単回帰の傾きと違い、他の変数の影響を取り除いた条件付きの意味になります。

### 重相関係数・偏相関係数
本文では、重回帰の予測値y_i と実測値 y_i の相関を重相関係数、その二乗を寄与率・決定係数 R^2 と説明しています。また、ある説明変数 X_j とYの関係を見るとき、他の説明変数の影響を取り除いた残差同士の相関を偏相関係数とします。

```
R^2=S_R/S_yy
偏相関: X_jを他のXで説明した残差と、Yを他のXで説明した残差の相関
```

具体例: 年齢X1と運動量X2で血圧Yを説明するとき、単純に年齢と血圧を見るだけでは運動量の影響が混ざります。偏相関は、運動量の違いをそろえた上で年齢と血圧を見る考え方です。

## 回帰分析で必ず確認すること
- 直線関係が妥当か。曲線関係なら線形回帰だけでは足りません。
- 外れ値が傾きを支配していないか。
- 残差のばらつきがXの値で変わっていないか。
- 相関・回帰は因果を保証しません。

## §5.3 分割表の解析
### 分割表とは
分割表は、カテゴリの組み合わせごとの度数を並べた表です。本文では、薬の有無Aと効果の有無Bのような 2×2 分割表から始め、a×b 分割表へ拡張しています。

```
2×2表:
        B1   B2   合計
A1     x11  x12  T1.
A2     x21  x22  T2.
合計   T.1  T.2  T
```

計量値データが「身長173cm」のような量を測るデータなのに対し、分割表は「効果あり/なし」「賛成/反対」のような個数を数えた計数値データです。

### 5.3.1 2×2分割表
2×2表では、2つの分類A,Bが独立か、または比率に差があるかを調べます。帰無仮説は「AとBは独立」または「2群の割合が等しい」と読めます。

```
期待度数 E_{ij}=T_{i.}T_{.j}/T
χ^2=Σ_iΣ_j (x_{ij}-E_{ij})^2/E_{ij}
自由度=(2-1)(2-1)=1
```

具体例: 新薬群100人中60人が改善、偽薬群100人中45人が改善なら、薬の種類と改善の有無が独立かを調べます。期待度数から大きくズレていれば、薬の効果がある可能性を考えます。

### フィッシャーの正確検定とマクネマー検定
度数が小さいとき、χ^2近似は粗くなることがあります。その場合は、2×2表で周辺度数を固定した正確確率を使うフィッシャーの正確検定が有効です。

```
フィッシャー: 小標本の2×2表で正確確率を計算
マクネマー: 対応のある2×2表で x12 と x21 の非対称性を見る
```

具体例: 同じ人に治療前後で「あり/なし」を聞くなら、独立な2群ではありません。変化した人数 x12 と x21 を比べるマクネマー検定を使います。

### 5.3.3 a×b分割表
カテゴリがa個とb個に増えても、基本は期待度数と観測度数のズレを見ることです。

```
期待度数 E_{ij}=T_{i.}T_{.j}/T
χ^2=Σ_iΣ_j (x_{ij}-E_{ij})^2/E_{ij}
自由度=(a-1)(b-1)
```

一様性の検定は「複数の行で列方向の分布が同じか」、独立性の検定は「AとBが独立か」と表現は違いますが、計算形は似ています。

! 分割表の注意: 期待度数が小さすぎるセルが多いと、χ^2近似が信用しにくくなります。カテゴリをまとめる、正確検定を使う、サンプル数を増やすなどを検討します。

## §5.4 ノンパラメトリック法
### ノンパラメトリック法の位置づけ
ノンパラメトリック法は、母集団分布が正規分布など特定の形であると強く仮定しない方法です。順位や符号を使うため、外れ値に比較的強く、小標本や順序尺度データにも使いやすいです。

! ただし「仮定が何もいらない」わけではありません。独立性、対応の有無、分布形のそろい方など、方法ごとの前提はあります。

### 5.4.1 符号検定
符号検定は、観測値 z_1,...,z_n の中央値が0かを調べる方法です。対応のある2変量 (x_i,y_i) では z_i=x_i-y_i と置けば、差の中央値が0かを検定できます。

```
m1=正の個数, m2=負の個数（0は除く）
H0: 中央値=0
H0の下で 正の個数 ~ Bin(m1+m2, 1/2)
```

具体例: 10人の治療前後の差で、改善が9人、悪化が1人なら、改善方向が偶然の半々と言えるかを二項分布で調べます。差の大きさではなく、符号だけを使います。

### 5.4.2 ウィルコクソン符号付き順位検定
符号検定は差の大きさを捨てます。ウィルコクソン符号付き順位検定は、差の絶対値に順位をつけ、符号つき順位の和を見るので、符号検定より情報を多く使います。

```
z_i=x_i-y_i
|z_i| に順位を付ける
正の差の順位和、または負の差の順位和で判断
```

具体例: 改善人数が同じでも、改善幅が大きく悪化幅が小さいなら、符号付き順位検定では改善傾向がより強く出ます。

### 5.4.3 ウィルコクソン順位和検定
独立な2群の分布位置を比べる方法です。2群のデータをまとめて順位をつけ、一方の群の順位和が極端に大きいまたは小さいかを見ます。マン・ホイットニーのU検定とほぼ同じ考え方です。

```
2群をまとめて順位付け
群1の順位和 R を計算
H0: 2群の分布位置に差がない
```

具体例: 薬A群と薬B群の回復日数を比べるとき、正規性が怪しい、外れ値がある、標本が少ない場合に使えます。

### 5.4.4 順位相関係数
順位相関は、値そのものではなく順位の対応で相関を見る方法です。本文ではスピアマンの順位相関係数とケンドールの順位相関係数が扱われています。

```
スピアマン: Xの順位 R_i と Yの順位 S_i の相関
ケンドール: ペアの大小関係が一致するかに注目
値の範囲はいずれも -1 から 1
```

具体例: 店の満足度順位と再来店意向順位の関係を見るなら、点数の間隔が等しいとは限らないため、通常の相関より順位相関が合うことがあります。

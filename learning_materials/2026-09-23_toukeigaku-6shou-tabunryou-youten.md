# 統計学6章 多変量解析の要点PDF

## 今日のテーマ
6章は、多変量データをまとめて見る章です。写真では、単回帰、重回帰、主成分分析、因子分析、クラスター分析、判別分析などが確認できました。このPDFでは、試験や演習で使いやすい形に整理します。

## 1. 単回帰分析
単回帰は、1つの説明変数xで目的変数yを説明する方法です。
```
y_i = a + b x_i + ε_i
```
最小二乗法では、残差平方和
```
Σ(y_i - a - b x_i)^2
```
を最小にします。

傾きと切片は
```
b = Σ(x_i-x̄)(y_i-ȳ) / Σ(x_i-x̄)^2
a = ȳ - b x̄
```
です。傾きbは「xが1増えると、yが平均的にどれだけ変わるか」を表します。

## 2. 決定係数
決定係数は、yのばらつきのうち回帰式で説明できた割合です。
```
R^2 = 1 - 残差平方和 / 全平方和
```
0から1の値を取り、1に近いほど直線でよく説明できます。ただし、説明変数を増やすとR^2は下がりにくいので、重回帰では自由度調整済み決定係数も見ます。

## 3. 重回帰分析
説明変数が複数あるときは
```
y_i = β0 + β1 x_1i + β2 x_2i + ... + ε_i
```
と書きます。

重回帰でよく見る表は3つです。
- 係数: 他の変数を固定したとき、その変数がyに与える影響。
- t値・P値: 各係数が0といえるかを検定する。
- F値・P値: モデル全体として説明力があるかを検定する。

注意点は多重共線性です。たとえば
```
Total = Listening + Reading
```
のような完全な関係があると、3つを同時に説明変数に入れることはできません。係数が一意に決まらないからです。

## 4. 主成分分析
主成分分析は、多くの変数を少数の合成変数にまとめる方法です。第1主成分は、データの分散が最も大きくなる方向です。

標準化した変数を使うとき、第k主成分は
```
Z_k = a_1 X_1 + a_2 X_2 + ... + a_p X_p
```
の形です。係数ベクトルは相関行列の固有ベクトル、主成分の分散は固有値になります。

寄与率は
```
第k主成分の固有値 / 固有値の合計
```
です。たとえば第1主成分の寄与率が60%なら、標準化された全体のばらつきの60%を第1主成分が説明している、という意味です。

## 5. 因子分析
因子分析は、観測された変数の背後にある見えない因子を仮定する方法です。主成分分析が「要約」なのに対して、因子分析は「背後の構造の説明」です。

因子負荷量は、各変数と因子の関係の強さを表します。負荷量が大きい変数を見て、その因子に名前をつけます。たとえば国語・社会が大きければ「文系力」、数学・理科が大きければ「理系力」と解釈できます。

## 6. クラスター分析
クラスター分析は、似ている観測値をグループに分ける方法です。

距離の定義と結合方法が重要です。
- ユークリッド距離: 点同士の通常の距離。
- 最短距離法: 2群の中で最も近い点同士の距離を見る。
- 最長距離法: 2群の中で最も遠い点同士の距離を見る。
- ウォード法: 群内平方和の増加が小さいようにまとめる。

結果はデンドログラムで表され、どの高さで切るかによってクラスター数が変わります。

## 7. 判別分析
判別分析は、すでにグループがわかっているデータから、新しいデータがどのグループに属するかを判定する方法です。

線形判別では、変数の線形結合
```
z = a_1x_1 + a_2x_2 + ... + a_px_p
```
でグループを分けます。ロジスティック回帰も、分類問題でよく使われます。

## よくあるつまずき
- 相関が高くても因果関係があるとは限りません。
- 回帰係数は「他の説明変数を固定したとき」の効果です。
- 主成分分析の符号は反転しても意味は同じです。大事なのは、どの変数が同じ向きに大きいかです。
- 因子分析の因子名は自動で決まるものではなく、負荷量を見て人間が解釈します。

## 確認問題
1. 単回帰の傾きbは何を意味するか説明しよう。
2. 重回帰で、モデル全体のP値は有意なのに個別係数が有意でない場合、何が起きている可能性がありますか。
3. 主成分分析と因子分析の目的の違いを一文で説明しよう。

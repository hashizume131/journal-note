# 統計学6章 本文網羅ノート

## 章全体の見取り図
6章は「多変量データをどう要約し、説明し、分類するか」の章です。写真で確認できた範囲では、回帰分析、重回帰、変数選択、主成分分析、因子分析、クラスター分析、判別分析、ロジスティック回帰、対応分析に近い図表の読み方まで扱っています。

! 6章は公式暗記よりも、出力表を読めることが大事です。係数、標準誤差、t値、P値、決定係数、固有値、寄与率、因子負荷量、デンドログラムなど、表や図が何を意味するかを押さえます。

## 6.1 単回帰分析
### モデル
```
y_i = a + b x_i + ε_i
```
`x` が説明変数、`y` が目的変数、`ε` が誤差です。

最小二乗法では
```
Σ(y_i-a-bx_i)^2
```
を最小にします。

推定式:
```
b = Σ(x_i-x̄)(y_i-ȳ) / Σ(x_i-x̄)^2
a = ȳ - b x̄
```
具体例: 勉強時間xと点数yなら、bは「勉強時間が1時間増えると点数が平均何点増えるか」を表します。

### 相関と回帰の違い
相関は対称です。xとyの関連の強さを見ます。回帰は非対称で、xからyを予測します。

注意: 相関が高くても因果関係とは限りません。

## 6.2 決定係数と回帰の検定
決定係数は、yの全体のばらつきのうち回帰式で説明できた割合です。
```
R^2 = 1 - 残差平方和/全平方和
```
具体例: `R^2=0.64` なら、yのばらつきの64%を回帰式で説明できたという意味です。

係数の検定:
```
H0: b=0
```
をt検定します。P値が小さければ、xはyの説明に役立つと判断します。

## 6.3 重回帰分析
### モデル
```
y_i = β0 + β1x_1i + β2x_2i + ... + βpx_pi + ε_i
```
βjは「他の変数を固定したとき、xjが1増える効果」です。

具体例: 期末点をListeningとReadingで説明するとき、Listeningの係数は「Readingが同じ学生同士で比べたListeningの効果」です。

### 回帰出力の読み方
- 係数: 効果の向きと大きさ。
- 標準誤差: 係数推定の不確かさ。
- t値: 係数/標準誤差。
- P値: 係数が0という仮説への反証の強さ。
- F値: モデル全体が役に立つか。
- 自由度調整済み決定係数: 説明変数の数を考慮した説明率。

### 多重共線性
説明変数同士が強く関係すると、個別係数が不安定になります。完全な関係があると推定できません。
```
Total = Listening + Reading
```
なら3つを同時に入れることはできません。

具体例: 身長cmと身長mを同時に説明変数に入れるのは、同じ情報を二重に入れているようなものです。

## 6.4 変数選択
重回帰では、説明変数を増やせば見かけのR^2は上がりやすいです。そのため、不要な変数を入れすぎない判断が必要です。

代表的な基準:
- P値: 有意でない変数を外す。
- 自由度調整済みR^2: 変数数のペナルティを考慮。
- AIC: 当てはまりとモデルの複雑さのバランス。

具体例: 期末点を予測するのに、Listening、Reading、Totalを全部入れるより、Totalだけの方が単純で安定する場合があります。

## 6.5 主成分分析
### 目的
多くの変数を、少数の合成変数にまとめます。第1主成分は、データの分散が最大になる方向です。

標準化した変数から作る主成分:
```
Z_k = a_1X_1 + a_2X_2 + ... + a_pX_p
```
係数ベクトルは相関行列の固有ベクトル、主成分の分散は固有値です。

### 固有値・寄与率・累積寄与率
```
寄与率 = 固有値 / 固有値の合計
```
累積寄与率は、複数の主成分でどれだけ情報を説明したかを表します。

具体例: 5科目の標準化データで第1主成分の寄与率が60%なら、「5科目全体のばらつきの60%を1本の総合得点で説明できる」という意味です。

### 主成分負荷量
主成分と元の変数の関係を表します。すべての科目で第1主成分負荷量が正なら「総合力」と解釈できます。国語・社会が正、数学・理科が負なら「文系対理系」の軸と読めます。

注意: 主成分の符号は全体を反転しても意味は同じです。プラス・マイナスそのものより、同じ向きか逆向きかを見ます。

## 6.6 因子分析
### 目的
観測変数の背後にある、直接見えない共通因子を考えます。

主成分分析との違い:
- 主成分分析: 情報を圧縮する。
- 因子分析: 背後の潜在構造を説明する。

### 因子負荷量
因子と各変数の関係の強さです。大きな負荷量を持つ変数を見て、因子に名前を付けます。

具体例: 国語・英語・社会の負荷量が高い因子は「文系能力」、数学・理科が高い因子は「理系能力」と解釈できます。

### 回転
因子を解釈しやすくするため、軸を回転します。バリマックス回転などが使われます。

注意: 因子名は自動で決まるわけではありません。負荷量表を見て人間が解釈します。

## 6.7 クラスター分析
### 目的
似ている観測対象をグループに分ける方法です。

距離の例:
```
ユークリッド距離 = sqrt(Σ(x_i-y_i)^2)
```

階層的クラスター分析では、デンドログラムを見ます。
- 最短距離法: 群間の最も近い点を見る。
- 最長距離法: 群間の最も遠い点を見る。
- 群平均法: 群間距離の平均を見る。
- ウォード法: 群内平方和の増加が小さいようにまとめる。

具体例: 5科目の点数パターンが似ている学生をグループ分けできます。総合的に高い群、文系が高い群、理系が高い群などです。

注意: 変数の単位が違うと距離が一部の変数に支配されるので、標準化が重要です。

## 6.8 判別分析
### 目的
既にグループがわかっているデータから、新しいデータの所属グループを予測します。

線形判別では
```
z = a_1x_1 + ... + a_px_p
```
のような判別得点を作ります。

具体例: 過去の合否データから、模試点・内申点を使って合格/不合格を判別するモデルを作るイメージです。

注意: 判別分析はグループの分散共分散構造に仮定を置きます。仮定が合わない場合はロジスティック回帰なども検討します。

## 6.9 ロジスティック回帰
目的変数が0/1のときに使います。確率pを直接線形回帰するのではなく、オッズの対数を線形モデルにします。
```
log(p/(1-p)) = β0 + β1x1 + ... + βpxp
```
具体例: 購入する/しない、合格する/しない、病気あり/なしのような二値データです。

係数βの指数 `exp(β)` はオッズ比として解釈できます。

## 6.10 図表の読み方
### 散布図
直線関係、外れ値、非線形関係を確認します。回帰をする前に必ず見たい図です。

### バイプロット
主成分分析で、観測対象と変数を同じ平面に表示します。近い点は似ていて、矢印の向きは変数の関係を示します。

### デンドログラム
クラスター分析で、どの対象がどの順に結合されたかを示します。切る高さでクラスター数が変わります。

## 6章のよくあるミス
- P値だけでモデルの良し悪しを決める。
- 決定係数が高いから因果関係があると思う。
- 重回帰係数を「単純な相関」と同じように読む。
- 主成分分析と因子分析を同じものとして扱う。
- 標準化せずに距離ベースの分析をして、単位の大きい変数に引っ張られる。

3. 主成分分析の第1主成分と因子分析の第1因子は何が違うか。
4. クラスター分析で標準化が必要になるのはどんな場合か。

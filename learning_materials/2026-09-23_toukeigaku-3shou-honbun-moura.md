# 統計学3章 本文網羅ノート

## 章全体の見取り図
3章は「標本から母集団を推測する」章です。写真で確認できた範囲では、標本と統計量、標本分布、大数の法則と中心極限定理、点推定、最尤推定、不偏性・一致性、フィッシャー情報量、クラメール・ラオ下限、区間推定、正規母集団の推測が中心です。

! 2章が「分布そのもの」を学ぶ章なら、3章は「分布のパラメータをデータからどう当てるか」を学ぶ章です。式だけでなく、推定量が何を推定しているかを常に確認します。

## 3.1 標本・統計量・標本分布
### 無作為標本
母集団分布から独立に同じ分布で取り出した変数を
```
X1, X2, ..., Xn
```
と書きます。これを無作為標本と呼びます。

具体例: ある大学生全体の身長分布から、学生を独立にn人選んで身長を測るイメージです。

### 統計量
標本から計算される量を統計量と呼びます。
```
標本平均: X̄=(1/n)ΣXi
標本分散: S_n^2=(1/n)Σ(Xi-X̄)^2
不偏標本分散: S^2=(1/(n-1))Σ(Xi-X̄)^2
```
統計量は標本に依存するので、それ自体が確率変数です。

### 標本分布
統計量の分布を標本分布と呼びます。たとえば `X̄` の分布は、nが大きくなると平均μの周りに集中します。

```
E[X̄]=μ
Var(X̄)=σ^2/n
```
具体例: 1人の点数は大きくばらついても、100人平均はかなり安定します。

## 3.2 大数の法則と中心極限定理
### 大数の法則
標本平均は、標本数が増えると母平均へ近づきます。
```
X̄ → μ
```
これは一致性の基礎です。

具体例: コインを10回投げた表の割合は大きくズレることがありますが、1万回投げれば0.5に近づきます。

### 中心極限定理
母集団が正規分布でなくても、条件が整えば標本平均は近似的に正規分布になります。
```
(X̄-μ)/(σ/√n) ≈ N(0,1)
```
具体例: 個々の購入金額が歪んだ分布でも、1日100人の平均購入額は正規分布に近づきます。

注意: 中心極限定理は「元のデータが正規になる」定理ではありません。「平均の分布」が正規に近づく定理です。

## 3.3 点推定
### 推定量と推定値
未知パラメータθを、標本から計算するルールが推定量です。実際のデータを代入して出た数値が推定値です。

例:
```
母平均 μ の推定量: X̄
母分散 σ^2 の推定量: S^2
```

### 不偏性
```
E[T]=θ
```
ならTはθの不偏推定量です。平均的に当たるという意味です。

具体例: 標本平均は母平均の不偏推定量です。何度も標本を取り直して標本平均を平均すると、母平均に一致します。

### 一致性
標本数nが増えると推定量がθに近づく性質です。

具体例: 標本平均は大数の法則により母平均の一致推定量です。

### 有効性
同じ不偏推定量同士なら、分散が小さいほどよい推定量です。ばらつきが小さいからです。

## 3.4 モーメント法
母集団の理論モーメントと標本モーメントを対応させて推定する方法です。

例: ポアソン分布では `E[X]=λ` なので
```
λhat = X̄
```
と置きます。

例: 正規分布なら、平均と分散を標本平均・標本分散に対応させます。

長所は計算が簡単なこと、短所は必ずしも効率がよいとは限らないことです。

## 3.5 最尤推定
### 尤度
観測データが得られる確率または密度を、パラメータの関数として見たものが尤度です。
```
L(θ)=Π f(xi;θ)
ℓ(θ)=log L(θ)
```
独立標本では積になります。対数を取ると和になり、微分しやすくなります。

### 例: 指数分布
```
f(x;λ)=λ exp(-λx), x≥0
ℓ(λ)=n log λ - λΣxi
```
微分して0に置くと
```
λhat=n/Σxi=1/X̄
```
です。

### 例: 正規分布
正規分布の平均μと分散σ^2を最尤推定すると
```
μhat=X̄
σhat^2=(1/n)Σ(Xi-X̄)^2
```
になります。分散の最尤推定量はnで割る形で、不偏分散とは違います。

注意: 最尤推定量は不偏とは限りません。ただし大標本ではよい性質を持つことが多いです。

## 3.6 フィッシャー情報量
### スコア関数
対数尤度をパラメータで微分したものをスコアと呼びます。
```
U(θ)=∂ log f(X;θ)/∂θ
```

### フィッシャー情報量
```
I(θ)=E[U(θ)^2]
```
または条件のよい場合
```
I(θ)=-E[∂^2 log f(X;θ)/∂θ^2]
```
で計算できます。n個の独立標本では
```
I_n(θ)=nI(θ)
```
です。

具体例: 指数分布 `f(x;λ)=λ exp(-λx)` では
```
log f=log λ-λX
∂log f/∂λ=1/λ-X
I(λ)=1/λ^2
```
です。

## 3.7 クラメール・ラオ下限
不偏推定量の分散には理論的な下限があります。
```
Var(T) ≥ {τ'(θ)}^2 / I_n(θ)
```
特にθ自身を推定するなら
```
Var(T) ≥ 1/I_n(θ)
```
です。

具体例: 指数分布のλを推定するとき、情報量が `n/λ^2` なら、任意の不偏推定量の分散は少なくとも `λ^2/n` です。

注意: 推定対象が `1/θ` のような関数なら、`τ'(θ)` を入れ忘れないこと。

## 3.8 十分統計量
標本の中で、パラメータ推定に必要な情報をまとめて持っている統計量です。因子分解定理で確認します。

```
f(x1,...,xn;θ)=g(T(x);θ) h(x)
```
と分解できれば、Tは十分統計量です。

具体例: ポアソン分布の独立標本では、和 `ΣXi` がλについての十分統計量になります。個々の順番より、合計回数が重要だからです。

## 3.9 区間推定
点推定値だけでなく、どのくらい不確かかを区間で示します。

### 母分散既知の母平均
```
X̄ ± z_(α/2) σ/√n
```
具体例: σ=10, n=100, X̄=60, 95%なら `60±1.96` です。

### 母分散未知の母平均
```
X̄ ± t_(α/2,n-1) S/√n
```
標本から分散も推定するため、標準正規ではなくt分布を使います。

### 正規母集団の母分散
```
(n-1)S^2/σ^2 ~ χ^2_(n-1)
```
を使って区間を作ります。

### 2つの分散比
2つの母分散を比べるときはF分布を使います。
```
(S1^2/σ1^2)/(S2^2/σ2^2) ~ F(n1-1,n2-1)
```

## 3.10 仮説検定とのつながり
信頼区間と検定はつながっています。たとえば95%信頼区間に仮説値が入らなければ、5%水準の両側検定では棄却されます。

検定では
- 帰無仮説 H0
- 対立仮説 H1
- 検定統計量
- 棄却域またはp値
を明確にします。

## 3章のよくあるミス
- 不偏性と一致性を同じものとして扱う。
- 最尤推定量がいつも不偏だと思い込む。
- 標本分散のn割りとn-1割りを混同する。
- 信頼区間を「真の値が確率95%で動く」と読んでしまう。
- クラメール・ラオ下限で推定対象がθかτ(θ)かを確認しない。

## ミニ確認問題
1. `X1,...,Xn` が平均μ、分散σ^2なら `Var(X̄)` はなぜ `σ^2/n` か。
2. 指数分布のλをモーメント法で推定してみよう。
3. 最尤推定量と不偏推定量の違いを説明しよう。
4. 母分散未知の平均の信頼区間でt分布を使う理由を説明しよう。

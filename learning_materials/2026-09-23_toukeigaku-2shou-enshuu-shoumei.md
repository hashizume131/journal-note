## 問2.1 二項分布の分散公式を示す
### 参照する本文公式
本文では、二項分布 B(n,p) の確率関数が
```
P(X=x) = C(n,x) p^x (1-p)^(n-x),  x=0,1,...,n
```
と与えられています。平均は `E[X]=np`、分散は `Var(X)=np(1-p)` です。

### 証明の流れ
ヒントの階乗モーメントを使います。
```
E[X(X-1)]
= Σ x(x-1) C(n,x) p^x (1-p)^(n-x)
```
ここで
```
x(x-1) C(n,x) = n(n-1) C(n-2,x-2)
```
なので
```
E[X(X-1)]
= n(n-1)p^2 Σ C(n-2,x-2) p^(x-2)(1-p)^(n-x)
= n(n-1)p^2
```
最後の和は二項分布 B(n-2,p) の確率の総和なので1です。

次に
```
E[X^2] = E[X(X-1)] + E[X]
       = n(n-1)p^2 + np
```
よって
```
Var(X) = E[X^2] - {E[X]}^2
       = n(n-1)p^2 + np - n^2p^2
       = np(1-p)
```
です。

## 問2.2 ポアソン分布の極限定理
### 参照する本文公式
ポアソン分布は
```
P(X=x) = exp(-λ) λ^x / x!,  x=0,1,2,...
```
です。二項分布 B(n,p) で `np=λ` を一定にして `n` を大きくすると、ポアソン分布が出ます。

### 証明
二項分布で `p=λ/n` とおくと
```
P(X=x) = C(n,x) (λ/n)^x (1-λ/n)^(n-x)
```
これを3つの部分に分けます。
```
C(n,x)(λ/n)^x
= λ^x / x! × n(n-1)...(n-x+1)/n^x
```
固定したxについて、nを大きくすると
```
n(n-1)...(n-x+1)/n^x → 1
```
また
```
(1-λ/n)^n → exp(-λ)
(1-λ/n)^(-x) → 1
```
なので
```
P(X=x) → exp(-λ) λ^x / x!
```
となります。これが「まれな事象をたくさん観測する」とポアソン分布になる理由です。

## 問2.3 分布関数と一様乱数の関係
### 参照する本文公式
連続型確率変数Xの累積分布関数を `F` とし、`F` が狭義単調増加で連続なら、`Y=F(X)` は一様分布 U(0,1) に従います。

### 証明
`0 < y < 1` とします。
```
P(Y ≤ y)
= P(F(X) ≤ y)
```
`F` は単調増加なので、両辺に逆関数を使って
```
P(F(X) ≤ y) = P(X ≤ F^(-1)(y))
```
となります。分布関数の定義より
```
P(X ≤ F^(-1)(y)) = F(F^(-1)(y)) = y
```
したがって `Y` の分布関数は `P(Y≤y)=y` です。これは一様分布 U(0,1) の分布関数なので、`Y~U(0,1)` です。

## 問2.4 ガンマ分布の和とベータ型の同時密度
### 問題の整理
独立な
```
X_i ~ Ga(α_i, β),  i=1,2,3
```
について、`X1/(X1+X2+X3)` と `X2/(X1+X2)` の同時密度を求める問題です。

### 参照する本文公式
ガンマ分布の密度は
```
f(x;α,β) = β^α / Γ(α) × x^(α-1) exp(-βx),  x>0
```
です。同じβをもつ独立なガンマ分布の和は、形状母数を足したガンマ分布になります。

### 証明の要点
次の変数変換を使います。
```
u = x1/(x1+x2+x3)
v = x2/(x1+x2)
s = x1+x2+x3
```
すると逆変換は
```
x1 = u s
x2 = (1-u) v s
x3 = (1-u)(1-v) s
```
ヤコビアンは
```
|J| = s^2(1-u)
```
です。

同時密度へ代入すると、sに関する部分と、u・vに関する部分に分かれます。
```
f(u,v,s) ∝ u^(α1-1) (1-u)^(α2+α3-1)
          v^(α2-1) (1-v)^(α3-1)
          s^(α1+α2+α3-1) exp(-βs)
```
sを0から∞まで積分するとガンマ積分で消え、求める同時密度は
```
f(u,v)
= Γ(α1+α2+α3) / {Γ(α1)Γ(α2)Γ(α3)}
  × u^(α1-1)(1-u)^(α2+α3-1)
  × v^(α2-1)(1-v)^(α3-1)
```
ただし `0<u<1, 0<v<1` です。ポイントは、同じβを持つため指数部分が `exp(-βs)` にまとまることです。

## 問2.5 一般化逆行列の形
### 参照する本文公式
本文の定理2.2.3は、退化正規分布の密度を、特異な共分散行列に対して一般化逆行列を用いて書くための公式です。

演習の行列は
```
A = [Iq  O]
    [O   Op-q]
```
です。この行列は前半q成分だけを残し、後半p-q成分を0にする射影行列です。

### 証明
一般化逆行列の条件の一つは
```
A A^- A = A
```
を満たすことです。ここで
```
A^- = [Iq  O]
     [O   Op-q]
```
と置けば、Aは対角ブロック行列なので
```
A A^- A = A A A = A
```
です。なぜなら、`Iq^2=Iq`、`O^2=O` だからです。したがってこのA自身が一般化逆行列の一つになります。

退化正規密度の式では、0でない固有値に対応する部分だけが実際の分散として働きます。後半の0成分は「その方向にはばらつきがない」という意味です。

## 問2.6 正規分布からガンマ分布
### 参照する本文公式
本文では、標準正規 `Z~N(0,1)` の2乗が自由度1のカイ二乗分布に従うこと、またカイ二乗分布はガンマ分布
```
χ^2_ν = Ga(ν/2, 1/2)
```
で表せることを使います。

### 証明
`X~N(0,1/θ)` とします。つまり分散は `1/θ` です。標準化すると
```
Z = √θ X ~ N(0,1)
```
なので
```
Z^2 = θX^2 ~ χ^2_1
```
です。したがって
```
θX^2 ~ Ga(1/2, 1/2)
```
となります。

定数倍の性質を使うと、`X^2 = (1/θ) Z^2` なので
```
X^2 ~ Ga(1/2, θ/2)
```
です。ここではガンマ分布を `β^α x^(α-1) exp(-βx)/Γ(α)` とする「率パラメータβ」の形で書いています。

## まとめ
- 二項分布の分散は階乗モーメント `E[X(X-1)]` を使うと短く証明できます。
- ポアソン分布は、二項分布で `n` が大きく `p` が小さく `np` が一定の極限です。
- 逆変換法の根本は `P(F(X)≤y)=P(X≤F^(-1)(y))` です。
- ガンマ分布の和・比の問題は、変数変換とヤコビアンが勝負どころです。

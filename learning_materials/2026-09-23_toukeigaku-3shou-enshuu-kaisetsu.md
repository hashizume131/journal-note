# 統計学3章演習 解説ノート

## 今日のテーマ
3章は、推定量の性質を確認する章です。キーワードは「変数変換」「一致性」「不偏性」「フィッシャー情報量」「クラメール・ラオの下限」「デルタ法」です。

## 問3.1 変数変換と効率的な推定量
### 問題の整理
確率密度関数は
```
f(x; θ) = θ(1+x)^-(1+θ),  θ > 0, x > 0
```
です。ここで `Y = log(1+X)` とおくと、分布が指数分布に変わるのが最大の着眼点です。

### (1) Y の密度・平均・分散
`Y = log(1+X)` なので `X = e^Y - 1`、また `dx/dy = e^y` です。密度の変数変換より
```
g(y) = f(e^y - 1; θ) e^y
     = θ(1+e^y-1)^-(1+θ) e^y
     = θ e^-θy,   y > 0
```
したがって `Y` はパラメータ `θ` の指数分布です。
```
E[Y] = 1/θ
Var(Y) = 1/θ^2
```
つまり、もとの `X` は扱いにくそうでも、`log(1+X)` にすると標準的な指数分布になります。

### (2) T が 1/θ の一致推定量であること
```
T = (1/n) Σ log(X_i + 1) = (1/n) Σ Y_i
```
です。`Y_i` は平均 `1/θ` の独立同分布なので、大数の法則により
```
T は E[Y] = 1/θ に近づく
```
となります。よって `T` は `1/θ` の一致推定量です。

### (3) T が不偏で、分散がクラメール・ラオ下限に一致すること
標本平均なので
```
E[T] = E[Y] = 1/θ
```
です。したがって `T` は `1/θ` の不偏推定量です。

分散は独立性より
```
Var(T) = Var(Y)/n = 1/(nθ^2)
```
です。

次に、`τ(θ) = 1/θ` を推定したいと考えます。1個の観測のフィッシャー情報量は `I(θ)=1/θ^2`、n個では
```
I_n(θ) = n/θ^2
```
です。また
```
τ'(θ) = -1/θ^2
```
なので、クラメール・ラオの下限は
```
{τ'(θ)}^2 / I_n(θ)
= (1/θ^4) / (n/θ^2)
= 1/(nθ^2)
```
これは `Var(T)` と一致します。つまり `T` は、この条件下でこれ以上分散を小さくできない効率的な不偏推定量です。

## 問3.2 指数分布の最尤推定とデルタ法
### 問題の整理
確率密度関数は
```
f(x) = λe^-λx,  x >= 0
```
で、`X_1, ..., X_n` は独立です。和を `T = X_1 + ... + X_n`、標本平均を `X̄ = T/n` とします。

### (1) 標本平均の期待値と分散
指数分布では
```
E[X] = 1/λ
Var(X) = 1/λ^2
```
です。したがって標本平均について
```
E[X̄] = 1/λ
Var(X̄) = 1/(nλ^2)
```
となります。

### (2) λ の最尤推定量
観測値を `x_1, ..., x_n` とし、和を `t` とします。尤度は
```
L(λ) = Π λe^-λx_i = λ^n e^-λt
```
対数尤度は
```
log L(λ) = n log λ - λt
```
微分して0に置くと
```
n/λ - t = 0
```
より
```
λhat = n/t = 1/X̄
```
です。

### (3) フィッシャー情報量
1個の観測では
```
log f(X; λ) = log λ - λX
∂ log f / ∂λ = 1/λ - X
```
このスコアの分散から `I(λ)=1/λ^2` です。n個なら足し合わせて
```
I_n(λ) = n/λ^2
```
となります。

### (4) デルタ法による λhat の漸近分散
`λhat = g(X̄)`、`g(u)=1/u` と見ます。`X̄` の平均は `μ=1/λ`、分散は `1/(nλ^2)` です。
```
g'(u) = -1/u^2
g'(μ) = -λ^2
```
デルタ法より
```
Var(λhat) ≈ {g'(μ)}^2 Var(X̄)
          = λ^4 × 1/(nλ^2)
          = λ^2/n
```
これはフィッシャー情報量の逆数 `1/I_n(λ)=λ^2/n` と同じです。

## よくあるつまずき
- 一致性は「nを大きくしたとき真の値へ近づく」性質で、不偏性は「期待値が真の値に等しい」性質です。別物です。
- クラメール・ラオ下限は、推定したい量が `θ` 自身でない場合、`τ'(θ)` を忘れます。今回の推定対象は `1/θ` なので、ここが重要です。
- デルタ法では、変換後の推定量を直接扱う代わりに、変換前の推定量の分散へ微分の2乗をかけます。

## 確認問題
1. `Y = log(1+X)` に変換したとき、なぜ `dx/dy = e^y` を掛ける必要があるか説明してみよう。
2. `λhat = 1/X̄` は `λ` の不偏推定量でしょうか。まず `E[1/X̄]` と `1/E[X̄]` が一般に等しくないことを確認しよう。
